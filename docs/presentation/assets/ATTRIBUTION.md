# Reader assets

- `flower-mcp-logo.png`: copied unchanged from the public Flower MCP logo.
- `github-markdown.css`: github-markdown-css, MIT, upstream revision
  `7f38dcb9054bc5d860fac65291f5c98fef47932c`.
  The trailing blank line was removed; style rules are unchanged.
  Source: https://github.com/sindresorhus/github-markdown-css
  License: `github-markdown-LICENSE.txt` in this directory.
- `reader.css` and `reader.js`: Flower presentation-specific navigation and layout.
- `method-authorities.png`, `method-plan.png`, `method-campaigns.png`: author-provided
  screenshots captured on 3 October 2026, cropped locally without generative AI.
  Only document-list areas are retained; source pixels were not rescaled or
  rewritten. EXIF and text metadata are removed. Original screenshots remain
  operator-owned and are excluded from Git and the source distribution.

The generated reader uses only local assets and system fonts. It does not load
scripts, fonts or styles from a CDN.
