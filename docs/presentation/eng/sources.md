## What you are reading

This is an editorial presentation, not a new server specification. Spazio Comune,
its rules and conversations are educational examples. They are not runtime
records, live receipts or a benchmark. Flower's current operational documentation
takes precedence over an introductory explanation.

The research also used internal development authorities and CodingCastle's
temporal-authority research as study material. **Their text was not exported into
this site**: no private documents, runtimes, hosts, credentials or logs. The
[method page](method.md) shows only cropped document lists selected by the author.
A CodingCastle engine capability is not attributed to Flower.

The public Flower sources below are pinned to
`ddc83c6c79638eda63edae5be1bd9789faa44a2e`, declared version `0.1.0`.
This is an editorial source snapshot, not new qualification of release binaries.
The reader is rebuilt from Markdown; product references must be reassessed when
server behavior changes.

## Explicit limits

- Flower does not guarantee agent correctness or adherence to recipes.
- Schema or PVP validation does not demonstrate semantic truth.
- Standalone Flower does not automatically audit external source code and symbols.
- The core is not a coding harness, deployer or monitoring service.
- A host report does not become provider attestation or a human decision.
- This site promises no token reduction, superior quality or autonomy for any
  particular model: those require separate benchmarks.
