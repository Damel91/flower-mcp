# Essential concepts, without memorizing a schema

[Index](README.md) · [Public tools](tools.md) · [Sources](sources.md)

## Responsibilities

Flower owns requirements, the Goal Graph, milestones, changes, plans, findings,
declared evidence, acceptance and handover. The agent and its technical tools
own repository investigation, code, builds, tests and Git. The person owns
intent and the final decisions assigned to them.

Flower's SQLite ledger is not the developed application's database. It does not
automatically contain its source code or proof that the agent read it.

## Lenses

A lens is an operational perspective on a project. The nine areas are bootstrap,
requirements, Goal Graph, milestones, changes, packet lifecycle, assurance,
handover and campaigns. They do not map one-to-one to the six narrative petals.

Selecting a lens changes attention, **not authorization, completion or truth**.
The client's MCP catalog is not magically hidden and recreated on every area
change. The current snapshot and gates retain their authority.

## Packets

A work increment with intent, scope and criteria. Its plan contains ordered
units, dependencies, instructions and checks. Readable numbers are stable
identities, not rankings to compact after a removal.

## PVP

The Packet Validation Projection is derived from canonical data, not a second
plan to maintain. It exposes criterion coverage, producers, consumers,
dependencies and verification obligations. A promise of future output does not
become existing source evidence.

Structural closure does not demonstrate semantic correctness or code quality.
The external workflow requires an accepted plan, closed PVP and current admission.
A relevant semantic finding can still block it.

## TODOs and exports

The TODO derives from the plan and current reports. It does not execute code.
A Markdown export transfers bounded authority; the host-saved file is useful
offline, but editing it does not change Flower's state.

## Current evidence

A report declares outcome, revision, artifacts and provenance. Flower checks
consistency with issued authority and preserves history. Host-declared evidence
does not mean source code audited by the server.

If the relevant authority changes, an earlier result can remain true as a
historical fact without completing the new work. A blind retry after a lost
response is not the right way to recover state.

## Three meanings of done

| Term | Meaning |
| --- | --- |
| Implemented | The material work is declared produced. |
| Verified | The required outcomes and evidence exist for that scope. |
| Accepted | The competent authority has made the required decision. |

They are not synonyms. Deferred checks remain open even when implementation
and local checks are complete. Progress without scope or a denominator is
unknown, not perfect.

## MCP in this story

The protocol lets a client call server tools. Markdown content guides the
model; structured content preserves machine-readable data. Flower does not
replace the system prompt, model, host permissions or agent adherence to recipes.
No internal model is required for core standalone workflows; some advanced
operations have their own prerequisites.
