from PVP preparation, first observed admission and the semantic findings subgate.

consent/delegation through the canonical operation and current fingerprint/reference.

context recovery and preview remain separately owned consumer behavior.

## Upgrade

Follow the [ordinary upgrade](UPGRADING.md#preparing-a-074-upgrade) in the existing
environment/profile. Retain the same SQLite database, YAML and client configuration.
The unchanged installer backs up before pip and rejects an active owner. Schema55,
dependencies and installer algorithm are unchanged; no migration or reset is needed.

## Verification boundary

Focused source regressions and independent severe review qualify preserved gates,
exact strings/counts, unchanged PVP/fingerprints and read-only SQLite state. Source
and installed public MCP checks use dedicated model-disabled state and exercise
simultaneous roadmap/PVP blocks plus ordinary repair and closed PVP still held by
roadmap admission. Existing Release CI gates the exact final public commit.
No benchmark execution, real consent, model usability, U6, product acceptance or
root-managed client upgrade is implied. Native adoption belongs to its owner.
